# Raph + Nova

Interactive demos showcasing Raph and Nova in graphical applications.

[Live demo](https://egorkozelskij.github.io/habr-examples-raph-nova/)

[Scene recordings](https://egorkozelskij.github.io/habr-examples-raph-nova/videos/)

The approved recordings are published as MP4 files without re-encoding. The graph recording exceeds GitHub's 100 MiB Git file limit, so its bytes are stored in two parts under `video-parts/`. The Pages workflow restores the original file and checks the size and SHA-256 of every video before deployment.
